# Reversi-Reimagined---Heuristic-Powered-Algorithmic-Play
This project showcases the development of an Othello (Reversi) AI, designed to demonstrate core principles of artificial intelligence in a classic board game setting. The AI employs the Minimax algorithm enhanced with Alpha-Beta Pruning to efficiently search game states and determine optimal moves. We've implemented multiple difficulty levels: a basic random player, a greedy disc-flipping strategy, and a sophisticated strategic player utilizing Minimax with a custom evaluative heuristic. This heuristic considers critical factors like positional weights, board mobility, and disc parity to make intelligent decisions.

The comprehensive C++ game engine supports both human-vs-human and human-vs-AI gameplay, with adjustable AI difficulty settings. A key feature includes a 'hint' system, which leverages the strategic AI to suggest optimal moves for human players.
